# 本地配方批次与放行

这是一个在本机运行的本地配方批次与放行。当前基线只提供可编译、可测试的起点。

## 使用

```bash
go test ./...
```

测试通过表示基线包可以加载。后续能力在这个模块上继续增加。

## 功能

`release` 包提供本地配方版本与批次投料台账：

- `Open(dir)` 打开指定数据位置的台账；空位置得到空台账，已有数据无法读取时返回
  `ErrCorruptData`，不会当作空台账继续保存。不同数据位置互相独立，程序退出后
  重新打开同一位置，已登记的数据完整可查。
- `RegisterRecipe` 登记配方版本（配方编号 + 版本号识别），每个版本包含名称和至少
  一种物料（物料编号 + 每份克数）；同一版本内物料编号不能重复，已登记内容不可覆盖。
- `CreateBatch` 建立草稿批次 → `UpdateDraft` 调整份数或改选配方版本 →
  `StartBatch` 开始执行（份数与配方固定）→ `AddFeeding` 分次追加投料 →
  `CloseBatch` 关闭确认。关闭后不能追加投料或重新打开。
- 克数用 `ParseGrams` 解析，要求正数且最多三位小数，数量核对按毫克精确计算；
  允许实际投料不足或超过应投量，以保留现场事实。
- `GetBatch` 返回配方版本、计划份数、状态、全部投料（按登记顺序），并逐项列出
  应投量、累计实投量和差额；没有投料的物料也会显示。返回的是副本。
- 每次写入都带请求编号：同一编号相同内容重放返回首次成功结果，同一编号用于
  另一操作或不同内容返回 `ErrRequestConflict`；失败不占用编号。并发提交安全。
